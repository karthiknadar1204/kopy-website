# Search research and page briefs

Reviewed 2026-11-21. Audience: English-speaking Mac users moving text and files between apps. Initial market assumption: English/global, with US queries used as a research starting point. Search volume is unknown; no paid keyword subscription or advertising was used.

## Observed results

Searches examined: “Mac clipboard history view previously copied text”, “Mac temporary file shelf drag files between windows”, and Apple's clipboard documentation. Results contain product pages, instructional guides, and forum questions. This is a qualitative web-search sample, not a measured Google rank or demand forecast.

- Apple documents clipboard history in macOS Tahoe and later: https://support.apple.com/en-us/102553 and https://support.apple.com/guide/mac-help/search-your-clipboard-history-mchl40d5b86b/mac . Do not claim all Macs retain only one clipboard item. Explain version differences and the limits of recovering content that was never captured.
- A real user question asks how to view previously copied content: https://www.reddit.com/r/MacOS/comments/qopvm7/how_to_view_everything_i_have_copied_and_pasted/ . Treat replies as user experience, not authoritative OS documentation.
- Maccy's product page emphasizes lightweight local clipboard history: https://maccy.app/ . Kopy's page should demonstrate its edge shelf, files, stacks, editable snippets and persistent Undo rather than promise superiority or speed without a comparison.
- Yoink's product page demonstrates a temporary drag-and-drop shelf: https://eternalstorms.at/yoink/mac/ . A practical file-transfer guide matches this task; Kopy must explain originals versus retained promised attachments and the difference between text paste and file dragging.

## Homepage brief

Buyer/task: a Mac user repeatedly switching windows to reuse text, screenshots and files. Intent: evaluate an edge clipboard/file shelf. Main answer: what Kopy does, what stays local, how activation works, supported macOS, and release availability. Evidence: actual fixture screenshots from the app and documented workflows. Next action now: inspect the app and test checkout. Public download and live purchasing wait for a signed distributable build. No baseline exists for this new website.

## Clipboard guide brief

Question: how to find previously copied text on a Mac. Explain Apple's current built-in option with its source, then Kopy's capture/search/pin/snippet workflow. State that Kopy cannot recover copies made before capture was enabled. Link to the product and support pages. Do not duplicate the guide for every keyword variation.

## File shelf guide brief

Question: how to move files between windows without holding a drag throughout navigation. Explain Finder drop, shelf reopening, stack grouping and drag-out with fixture files. Describe copy semantics, original-file availability and deactivation-independent local history. Link to product/support and cite the source for OS-specific instructions.
